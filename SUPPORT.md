# Support

LumenPlot is pre-alpha, the public API is unstable, and production use is not
recommended. Support is best-effort and is limited to the repository workflows
that maintainers have enabled.

## Where to ask

- **Reproducible bugs:** use the GitHub bug report form and include the smallest
  reproduction, expected behavior, actual behavior, environment, and commands
  run.
- **Feature proposals:** use the feature request form and explain the user
  problem, proposed behavior, compatibility impact, and alternatives.
- **Architecture or cross-cutting changes:** start with an issue and follow
  the ADR-first process in [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md), never a
  public issue.
- **Conduct concerns:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), never
  include sensitive details in a public issue or pull request.

The audited remote had GitHub Issues enabled and Discussions disabled. Those
settings can change; maintainers must verify the actual public settings before
relying on them. This baseline does not publish an email address or claim a
private support channel that the audit could not confirm.

## Scope and expectations

Please provide a minimal reproduction and the exact toolchain or runtime
information needed to reproduce a problem. There is no guaranteed response
schedule, compatibility promise, or production support SLA for pre-alpha
software. Maintainers may close requests that require an unsupported capability,
private API compatibility, or an unverified performance guarantee.
