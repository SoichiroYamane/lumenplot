# Architecture decision records

Sol owns architecture decisions; Luna records accepted decisions here as
`NNNN-short-title.md` files.

Each ADR should state:

1. context and the problem
2. decision
3. alternatives and rationale
4. consequences and compatibility impact
5. affected interfaces and required verification

Do not record an ADR for routine local implementation details. Keep the
repository's decisions reviewable and independent of Hermes profile memory.
